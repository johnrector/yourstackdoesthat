Contribute

Add an entry. No account here required.

Everything on this site is a plain text file in a public repository. Add a Does entry or a Cancel Ledger line either way below. Whatever you contribute is released to the public domain under CC0, the same as everything else here. Do not contribute anything you are not willing to give away.

The repository

The site lives at {{repo}}. Entries are markdown files, one per entry. Open a pull request and it will be read by a person. There is a CONTRIBUTING file in the repository with the format, and the existing entries are the best examples.

---
title: Know when a bill is about to be late
domain: money
added: 2026-09-06
uses: connector, scheduled task
setup: A connector to the bank, or statements forwarded to a folder.
---

A Cancel Ledger line looks like this:

---
replaced: A social media scheduler
cost: $15 a month
replaced_by: A scheduled task and a connector to the account
result: replaced
date: 2026-09-06
---
One or two sentences, optional.

The rules for entries

  • Provider-neutral. Do not name a frontier stack as the one that does it. If only one of them can do it today, say "in some stacks" and describe what is needed.
  • Honest about setup. If it took you a weekend, say so. "With setup" is a real answer.
  • Categories, not brands, in the ledger. "A grammar checker," not the company. A product that lost to a skill file did nothing wrong.
  • No selling. Nothing that links to a thing for sale, including your own.
  • Short declarative sentences. No hype.

Or send it here

If you would rather not use the repository, use one of these. They go to the host of this site and nowhere else; no third-party form service is involved. A person reads them and turns the good ones into files. Nothing you type is used for anything but that. You do not have to give a name or an address, and there is no field for one.

A Does entry

Name the part of the stack: a connector, a skill, a scheduled task, or a combination. Say what still requires setup.

A Cancel Ledger line

Submissions are stored by the host until a person reviews them, then deleted. Anything that names a person or a company is edited or dropped before it is merged. Anything that sells is dropped.
